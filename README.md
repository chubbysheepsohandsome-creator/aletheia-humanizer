# ALETHEIA Humanizer

在浏览器中运行的英文改写实验工具。离线规则、逐词对比、内容检查和 ALETHEIA 四档评测在浏览器中完成。

## 打开

项目地址：https://github.com/chubbysheepsohandsome-creator/aletheia-humanizer

GitHub Pages 发布源：main 分支，根目录。index.html 是完整单文件页面，无需安装、构建或后台服务。

本地也可直接双击 index.html。支持粘贴、TXT、Markdown、DOCX 和带文字层的 PDF。

## 可选模型

深度改写需连接已启动且允许浏览器访问的 Ollama，或用户自行配置 API。密钥只在页面会话内存使用，文稿不自动保存。选择 API 时文本会发送给提供方。

## 当前状态

实验版。本轮少量合成稿测试没有观察到可靠降分。规则检查和同模型复核都不能证明原意完全等价；使用前需人工核对。检测分数不能证明作者身份。

页面内嵌全部运行资源。第三方许可见 LICENSE-pdfjs.txt、LICENSE-fonts-OFL.txt 和 NOTICE.md。
